# Report logos

`bitcoin-com.png` is the official Bitcoin.com wordmark from
https://www.bitcoin.com/logo-light.webp, retrieved 2026-11-17 and converted
losslessly to PNG for PDF embedding. The artwork, colors, and proportions are
preserved. Source website: https://www.bitcoin.com/.

The local file is used by the PDF exporter. It is bundled with the app so
rendering the branding does not contact an external server.
